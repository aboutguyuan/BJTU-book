# 北京交通大学生存手册

一份面向北京交通大学新生与在校生的非官方学生指南。手册从真实的校园生活和成长选择出发，整理大学期间常见的信息差、规则、路径与风险，帮助读者更清楚地认识处境、规划行动并减少不必要的试错。

[在线阅读《北京交通大学生存手册》](https://aboutguyuan.github.io/BJTU-book/)

> 本手册不是学校官方文件。涉及学籍、选课、成绩、毕业、推免、就业手续和校区安排等事项，请以学校、学院及辅导员的正式通知为准。

## 内容概览

### 入学与校园生活

介绍学校与校区的基本情况，以及新生报到、信息获取、宿舍相处、校园资源、北京生活和人际关系等内容，帮助读者尽快建立稳定的大学生活秩序。

### 课程、绩点与专业选择

说明培养方案、选课、考试、绩点、排名、转专业和辅修等常见问题，讨论如何理解规则、核验信息，并在短期成绩与长期能力之间找到适合自己的平衡。

### 科研、竞赛与能力积累

梳理科研入门、竞赛选择、项目参与、社团活动和表达协作等主题，重点关注一段经历能否形成真实能力、有效作品和可复用的方法，而不只是增加简历条目。

### 升学与就业路线

集中介绍保研、考研、出国和读博的选择逻辑，也覆盖实习、求职、考公、选调和签约等就业方向。内容包括院校与项目选择、准备时间线、信息核验、备考心态、复试调剂以及路线切换的预案。

### 风险处理与长期规划

讨论学业压力、心理状态、突发事件、校园事务、消费与兼职风险，以及大学四年的阶段规划。手册既提供问题发生后的处理入口，也强调提前保存材料、确认规则和建立支持系统。

### 实用模板

附录保留了给老师发邮件和撰写简历项目描述的实用模板，方便读者结合自己的实际情况修改使用。
