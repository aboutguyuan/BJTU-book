## 第十七章 常见问题导航：先看结论，再去正文

这一章只提供快速判断和阅读入口，不再把宿舍、绩点、科研、社团、升学和雄安的正文重写一遍。

### 17.1 高频问题速查

| 问题 | 现在先做什么 | 详细内容到哪里看 |
| --- | --- | --- |
| 我刚进校就后悔了，怎么办？ | 先分清是生活不适、专业误解还是长期不匹配，给自己一个有行动的信息收集期 | 第二章；生活问题看第四章，专业问题看第七章 |
| 宿舍关系很差，要不要换宿舍？ | 先区分生活习惯差异和安全、骚扰、侮辱等不能只靠沟通解决的问题 | 第四章 4.2—4.3；紧急风险看第十八和二十四章 |
| 绩点不高是不是完了？ | 先判断影响哪些路线，止住继续下滑，再补替代竞争力 | 第六章 6.4；学习方法看第二十二章 |
| 没有科研经历怎么办？ | 先问自己为什么需要科研，再从课程项目、小课题或基础工作开始 | 第八章 8.2 和 8.6 |
| 要不要加入很多社团？ | 不要用数量证明充实；看这个组织是否带来能力、关系、体验或成果 | 第九章 9.1 和 9.3 |
| 要不要买很贵的电脑？ | 先核对专业课程、软件、仿真、设计或编程需求，再设预算 | 入学准备看第二章，专业工具问同专业高年级和学院，预算看第十章 |
| 保研、考研、就业能不能同时准备？ | 大一大二可以维护共同基础，大三必须确定主次 | 第十一、十二、十六和二十章 |
| 雄安校区会不会影响我？ | 只核对自己的学院、专业、年级、课程和正式通知 | 第十四章；第一章只是概览 |
| 我觉得自己和周围人差距很大，怎么办？ | 把“差距”拆成成绩、项目、英语、信息、资源或表达中的具体一项 | 身心状态看第四章；具体能力分别看第六、八、十五章 |
| 我不知道未来想做什么，怎么办？ | 先完成小规模真实探索，同时维护成绩、英语、工具、项目和健康等通用筹码 | 第十五、十六、二十和二十六章 |

### 17.2 快速结论不能代替判断

如果问题涉及正式规则、截止日期、资格、学分、合同、人身安全或健康，不要只依赖这张表。先到对应正文看判断方法，再核对当年文件并联系正确入口。如果情况紧急，直接使用第十八章的场景入口。
