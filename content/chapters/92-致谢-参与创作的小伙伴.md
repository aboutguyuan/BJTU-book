## 致谢：参与创作的小伙伴

这部分用于展示参与创作、反馈、校对、资料补充和建议的小伙伴。

### 参与方式

欢迎通过以下方式参与：

- 提交勘误。
- 补充具体场景经验。
- 提供资料来源和政策链接。
- 协助校对错别字、格式和表达问题。
- 对某一章节提出补充或反对意见。

### 投稿格式

为了方便核实和整理，建议投稿时尽量包含以下信息：

| 项目 | 说明 |
| --- | --- |
| 对应章节 | 例如“第十二章 就业和实习”或“附录 A 新生第一周清单” |
| 问题描述 | 你认为哪里不准确、不完整或需要补充 |
| 建议修改 | 可以直接写建议文字，也可以只写要点 |
| 依据来源 | 官方通知、亲身经历、同学访谈、公开链接或截图线索 |
| 适用范围 | 哪个学院、年级、校区、专业或时间段 |
| 是否署名 | 真实姓名、昵称、GitHub 用户名或匿名 |

如果投稿涉及具体同学、老师、宿舍、课程或单位，请先去掉可以直接识别个人身份的信息。

### 收录规则

本手册会优先收录三类内容：

1. 能被官方通知、公开资料或多名同学经验相互印证的内容。
2. 能说明适用范围的具体经验，比如某一年级、某学院、某校区、某类专业。
3. 能帮助后来者做判断和行动的案例，比如时间线、材料清单、沟通方式和踩坑点。

经验可以带有主观感受，但写入正文前需要尽量转化成事实、影响和建议。

### 不收录规则

以下内容原则上不直接收录：

- 未经核实的攻击、指控或传言。
- 涉及个人隐私、联系方式、宿舍号、身份证明和敏感经历的内容。
- 已经明显过期、但没有标注时间背景的政策经验。
- 只有情绪宣泄、无法提炼出事实或建议的吐槽。
- 可能误导读者把单一经历当成全校规则的内容。
